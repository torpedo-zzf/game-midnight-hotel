# 午夜酒店 · M1 浏览器原型

根据《午夜酒店产品需求文档》v0.1 的 M1 范围制作的本地开发原型。当前包含一间房间、一名角色、照片/窗户/房门三个热点、可翻看的照片线索、窗外观察、预设中文语音与字幕、敲门事件、分支结局、暂停与设置。无需安装依赖或连接网络。

## 在线体验

[打开 GitHub Pages 预览](https://torpedo-zzf.github.io/game-midnight-hotel/)。手机可直接使用浏览器访问，建议横屏并开启声音。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm start
```

在桌面浏览器打开 `http://127.0.0.1:4173`。运行 `npm test` 检查剧情状态规则。

## 操作

- 鼠标移动：有限视角平移；点击发光热点进行互动。
- Tab 和 Enter：键盘选择并触发热点。
- Esc：暂停、继续或退出当前面板。
- 暂停菜单：音量、字幕大小、减少动态效果、确认后重新开始。

## 当前范围与待完成项

这是一份可交互的视觉原型，尚未达到 PRD 的 M1 视觉验收。角色立绘、房间和线索照片是生成的原型素材。Mira 已有平静、紧张、惊讶、闭眼和张嘴的原型状态：身体使用同一底图，紧张状态只替换眉眼，惊讶状态替换整张脸；眨眼只用于平静状态，嘴部在平静和紧张对白中随音量开合。当前口型并非按音素精确对齐，惊讶状态没有独立口型，注视仍未随视点移动。中文对白使用 macOS Tingting 合成语音作为临时占位，环境雨声与敲门声由浏览器实时合成。需要补齐正式对齐的分层素材与真人录音，再进行 1080p/720p 边界、三分钟循环、性能和五人体验验收。M2 AI 对话及 M3 世界模拟不在此版本。

## 文件

- `src/story.js`：纯状态逻辑、线索与预设剧情分支。
- `src/main.js`：界面、输入、时间线、中文语音与合成环境音。
- `assets/manifest.json`：素材版本、尺寸、定位与来源。
- `tests/story.test.js`：重复线索、暂停、分支与重启回归测试。
