# 午夜酒店 · M1 浏览器原型

根据《午夜酒店产品需求文档》v0.1 的 M1 范围制作的本地开发原型。当前包含一间房间、一名角色、照片/窗户/房门三个热点、预设对白、敲门事件、两种选择结果、暂停与设置。无需安装依赖或连接网络。

## 运行

需要 Node.js 20 或更新版本：

```bash
npm start
```

在桌面浏览器打开 `http://127.0.0.1:4173`。运行 `npm test` 检查剧情状态规则。

## 操作

- 鼠标移动：有限视角平移；点击发光热点进行互动。
- Tab 和 Enter：键盘选择并触发热点。
- Esc：暂停、继续或退出当前面板。
- 暂停菜单：音量、字幕大小、减少动态效果、确认后重新开始。

## 当前范围与待完成项

这是一份可交互的视觉原型，尚未达到 PRD 的 M1 视觉验收。角色立绘和房间图是生成的原型素材；Mira 尚无成套表情、独立眼部与口型素材，也没有预录中文对白。环境雨声与敲门声由浏览器实时合成。需要补齐正式分层素材、角色动画与录音，再进行 1080p/720p 边界、三分钟循环、性能和五人体验验收。M2 AI 对话及 M3 世界模拟不在此版本。

## 文件

- `src/story.js`：纯状态逻辑与预设剧情分支。
- `src/main.js`：界面、输入、时间线和合成音频。
- `assets/manifest.json`：素材版本、尺寸、定位与来源。
- `tests/story.test.js`：重复线索、暂停、分支与重启回归测试。
